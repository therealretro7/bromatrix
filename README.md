# Bromatrix | Hardware R&D, IoT, Robotics & UAV Innovation Hub

![Bromatrix Banner](https://lh3.googleusercontent.com/d/1TqfPvWOl5UlKmsj3iscYnki5sNk7sa7w=w1000)

Bromatrix is an advanced hardware research and practical engineering innovation hub pioneering hands-on training, embedded firmware, autonomous robotics, custom CAD/CAM prototyping, and aerial UAV drone development.

---

## 🚀 Key Features

- **Dynamic Assembling Drone & Full-Screen Patrol**:
  - Full-screen flight paths across all sections with banking inertial physics and auto-leveling.
  - Interactive CAD Exploded View: splits into 8 modular sub-assemblies (carbon arms, brushless motor pods, 4S LiPo battery pack, 4K optical lidar gimbal, and flight controller core) with laser alignment tracers and technical callouts.
  * Interactive action bar for Exploded View toggle, Autopilot figure-8 recon patrol, and 360° acrobatic barrel rolls.
- **Interactive 3D Topographic Horizon & Cyber Wave Canvas**:
  - High-performance 60 FPS HTML5 Canvas elevation mesh with real-time terrain wave equations.
  - Interactive cursor ripple gravity displacement.
  - Live drone ion-flux tracking: casts glowing aero-cyan and emerald illumination directly beneath the flying drone.
  - Drifting cyber telemetry motes.
- **Aerotech Obsidian & Liquid Glass UI**:
  - Obsidian theme (`#040711`) with frosted liquid glassmorphic cards (`backdrop-filter: blur(24px)`).
  - Caustic hover spotlights and iridescent gradient sweeps.
  - Clean native mouse cursor (no obstructive custom dots).
- **Field Ops & Real Media Archive**:
  - Direct integration with official Google Drive archives (Tech-Fest AJEC Championship win, Summer Internship 2026, and Internship 2.0 practical labs).
  - Live filter categories and high-resolution fullscreen modal lightbox.
- **Interactive STEM & Hardware Tools**:
  - Hardware System Topology Diagrams (IoT Node, Autonomous Quadcopter, R&D Rapid Prototyping).
  - Live AI STEM Advisor powered by Gemini API with practical hardware curriculum fallbacks.
  - Dynamic Workshop Scope & Timeline Estimator.

## 💻 Quick Start & Deployment

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/therealretro7/bromatrix.git
   cd bromatrix
   ```

2. **Run Locally**:
   Open `index.html` in any modern desktop or mobile browser. No build steps or web server required!

3. **Deploy via GitHub Pages**:
   - Go to your repository settings on GitHub.
   - Navigate to **Pages** > **Branch: main** > **Save**.
   - Your site will be live on `https://therealretro7.github.io/bromatrix/`.
